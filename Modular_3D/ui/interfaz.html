Componentes del espacio
Sobremedida de este espacio Igual que la sobremedida del casco general: un valor positivo hace que ese panel sobresalga hacia adelante o atrás; negativo lo retranquea. Solo aplica a los paneles activados arriba (no a travesaños ni respaldo).
Interior y frente
Cajones de este espacio
Espacio entre cajones: por defecto 1.5 mm entre cajón y cajón (misma fuga que usan las puertas), y entre el primero/último y la base, techo o repisa que los encierra. Si tu sistema de corredera necesita más holgura mecánica, subí este valor. Altura de cajón en 0 = automático (reparte el alto disponible en partes iguales); un valor mayor a 0 fija esa altura para cada cajón.
"Uno por cajón": cada cajón tiene su propio frente. "Único": un solo frente cubre toda la pila de cajones y se desliza junto con el cajón más bajo; los demás cajones de esa columna se siguen abriendo aparte con Interactuar, pero sin frente propio (quedan ocultos detrás del frente único mientras están cerrados). "Falso": un panel fijo que no se abre; en ese espacio no se crea ningún cajón.
Puerta de este espacio
Selecciona el espacio padre para crear una o dos puertas que cubran todos sus espacios hijos.
Con 1,5 mm por cada hoja, la junta visible entre dos puertas es exactamente 3 mm.
Los cambios de este espacio se aplican de inmediato al visor 3D; no hace falta guardarlos.
